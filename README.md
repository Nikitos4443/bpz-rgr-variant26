# РГР з «Безпеки програмного забезпечення» — варіант 26

Аудит захищеності OWASP Juice Shop (Node.js), профіль **обхід контролю доступу**.
Студент: Шульга Нікіта Сергійович, гр. ІП-33.

## Структура репозиторію

- `juice-shop/` — ціль аудиту (OWASP Juice Shop v18.0.0). Коміт `baseline` —
  незмінений застосунок; коміт `fixes` — внесені виправлення.
- `threat_model/` — модель загроз: `dfd.dot`/`dfd.svg`/`dfd.png` (DFD з межами
  довіри), `stride.md` (STRIDE по елементах і потоках), `risk_register.md` (реєстр
  ризиків із CVSS 3.1).
- `exploits/` — PoC-скрипти семи підтверджених вразливостей (`poc1…poc7`), спільний
  модуль `common.py`, збережені виводи `before_output/` та `after_output/`.
- `tests/` — регресійні тести (`test_access_control.py`), що повторюють кожен
  експлойт і перевіряють його блокування.
- `scans/before/` та `scans/after/` — «сирі» звіти Semgrep, npm audit, Gitleaks
  до і після виправлень.
- `report/` — джерело звіту (`RGR_report.md`), збірник DOCX (`build_docx.js`) та
  підсумковий PDF.
- `tools/` — калькулятор CVSS 3.1 (`cvss31.py`).

## Розгортання (лише локально, 127.0.0.1)

```
cd juice-shop
npm install
npm run build:server
NODE_ENV=unsafe PORT=3000 node build/app     # слухає 127.0.0.1:3000
```

## Відтворення перевірки

```
# Демонстрація експлойтів (проти baseline — успішні, проти fixes — заблоковані)
python3 exploits/poc1_basket_idor.py

# Регресійні тести (проти застосунку з виправленнями — усі проходять)
python3 tests/test_access_control.py
```
